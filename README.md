# Reorganization of large-scale network dynamics after early visual deprivation

This repository contains the code associated with the paper:

**Reorganization of large-scale network dynamics after early visual deprivation**

Caterina A. Pedersini, Bas Rokers, and Olivier Collignon.

The analysis pipeline includes the following steps:

1. **Hidden Markov Model (HMM) estimation:** Estimation of an HMM on concatenated resting-state fMRI data, including optimization of the number of brain states (K).

2. **Chronnectome analysis:** Assessment of between-group differences in temporal brain network dynamics using three HMM-derived metrics:
   Fractional Occupancy (FO), Mean Lifetime (ML), and Switching Rate (SR).

4. **Functional connectivity gradients:** Estimation of functional gradients and assessment of between-group differences in the functional embedding
   of the unimodal–transmodal and visual–sensorimotor gradients.
